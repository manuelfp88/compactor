# compactor

Un botón 🗜️ en el pie del cuadro de escribir de Claude Code para compactar la conversación con un clic.

- Muestra el porcentaje del contexto usado y, a su lado, los tokens (por ejemplo `144.7k / 1M`).
- Se activa cuando el contexto pasa del 75 % y Claude no está trabajando. Antes se ve en gris.
- Al pulsarlo, compacta la conversación, igual que `/compact`.

## Instalación

En una sesión de Claude Code en la terminal:

```
/plugin install compactor --marketplace manuelfp88/compactor
```

Responde `y` para añadir el catálogo y elige dónde instalarlo.
